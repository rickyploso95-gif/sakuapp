# SakuApp - Aplikasi Pengelola Keuangan & Catatan Tabungan

## Judul & Deskripsi
* *Nama Produk Digital:* SakuApp (Personal Finance & Savings Tracker)
* *Latar Belakang Masalah:* Banyak individu, siswa, maupun masyarakat umum kesulitan dalam mencatat arus kas harian serta menjaga konsistensi menabung. Pencatatan manual seringkali merepotkan, sedangkan aplikasi modern kerap terlalu rumit atau memerlukan akses akun/pembayaran berbayar. SakuApp hadir sebagai solusi berbasis web yang mudah diakses, tanpa perlu login, ringan, serta menjaga privasi data pengguna.
* *Target Pengguna:* Siswa, mahasiswa, pekerja lepas, dan masyarakat umum yang membutuhkan alat bantu praktis untuk mencatat pengeluaran, pemasukan, serta memantau target tabungan impian secara visual.

---

## Teknologi yang Digunakan
* *Bahasa Pemrograman:* HTML5, CSS3, JavaScript (ES6)
* *Modul / Pustaka (Library):*
  * [Tailwind CSS](https://tailwindcss.com/) (CDN) - Kerangka kerja UI/Styling responsif
  * [Font Awesome 6](https://fontawesome.com/) - Ikon antarmuka
  * [Chart.js](https://www.chartjs.org/) - Visualisasi grafik arus kas & alokasi pengeluaran
* *Platform Publikasi / Hosting:* GitHub Pages / Netlify Drop (Static Web Hosting)

## Panduan Penggunaan
1. *Akses Situs Web:* Buka tautan situs web aktif melalui peramban (browser) Anda di:  
   https://[username-github].github.io/[nama-repositori]/ (Ganti dengan link web aktif Anda)
2. *Langkah Penggunaan Aplikasi:*
   * *Pencatatan Transaksi:* Masukkan transaksi baru (Pemasukan / Pengeluaran), pilih kategori, isi nominal serta tanggal, lalu klik Simpan Transaksi.
   * *Target Tabungan:* Buka tab Catatan Tabungan, klik Buat Target Baru, lalu isi nama target dan nominal impian.
   * *Setor / Tarik Tabungan:* Gunakan tombol Setor untuk mengalokasikan Saldo Bebas ke target tabungan Anda.
   * *Analisis & Grafik:* Buka tab Laporan & Analisis untuk melihat diagram visual arus kas dan kategori pengeluaran.
   * *Backup Data:* Manfaatkan fitur Export JSON/CSV pada tab Export / Backup untuk menyimpan cadangan data Anda.
